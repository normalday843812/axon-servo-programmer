# Changelog

## 0.2.0 (2026-11-20)

First public release.

- Read, change, save, load and factory-reset the settings of Axon MK2 servos
  through the Axon Servo Programmer MK2.
- Flash firmware to switch a servo between Servo mode and CR mode.
- Signal output for testing a servo, and a live voltage and current readout.
- Standalone downloads for macOS, Linux and Windows.
